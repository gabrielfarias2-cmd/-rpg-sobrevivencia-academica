## Registro 01 – Planejamento das classes do RPG

**Problema:**

O grupo precisava entender como organizar as classes do jogo RPG Sobrevivência Acadêmica utilizando Programação Orientada a Objetos em Java.

**Prompt:**

Como podemos organizar as classes de um RPG de sobrevivência acadêmica em Java, utilizando conceitos de POO como herança, encapsulamento, polimorfismo e abstração?

**Sugestão da IA:**

A IA sugeriu organizar o projeto com uma classe principal abstrata, classes específicas para os personagens, classes para os inimigos, itens e uma classe responsável por controlar a partida.

**Decisão do grupo:**

O grupo decidiu utilizar as sugestões como base para o planejamento das classes, adaptando-as às características e à história do RPG Sobrevivência Acadêmica.

**Teste realizado:**

Ainda não realizado. O planejamento será analisado pelo grupo antes de iniciar a implementação das classes em Java.
